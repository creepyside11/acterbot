# Acterbot

Telegram-установщик Aster для своего VPS. Один бот управляет установкой, показывает загрузку сервера, открывает веб-панель и передаёт задания Aster. Установщик и Aster хранят свои данные в SQLite.

## Запуск установщика

Создайте бота у [@BotFather](https://t.me/BotFather). В каталоге репозитория скопируйте `.env.example` в `.env` и заполните единственную переменную `BOT_TOKEN`. Используйте новый токен или остановите прежний сервис с этим токеном перед запуском.

```bash
docker compose up -d --build
docker compose logs installer
```

Команда из журнала `/claim КОД` привязывает владельца. Отправьте её боту в личном Telegram-чате в течение 30 минут. Если код истёк, получите новый через `docker compose exec installer python -m installer claim`.

Без Docker установщик запускается на Python 3.12 из корня репозитория.

```bash
python -m pip install -r requirements.txt
python -m installer
```

Для развёртывания на хостинге укажите `python -m installer` как команду запуска и добавьте `BOT_TOKEN` в переменные окружения. Храните каталог `state/` на постоянном диске. Установщик работает через Telegram long polling и не требует входящего HTTP-порта. [Telegram Bot API](https://core.telegram.org/bots/api#getupdates)

## Установка Aster на VPS

1. Отправьте боту `/install`.
2. Введите публичный IPv4 или IPv6. Для нестандартного SSH-порта введите IP и порт через пробел.
3. Введите SSH-логин. Для установки нужен `root` или пользователь с `sudo -n` и доступом к SFTP. Поддерживаются Ubuntu и Debian с пакетами Docker для соответствующего выпуска. [Репозиторий Docker](https://docs.docker.com/engine/install/ubuntu/)
4. Сверьте отпечаток SSH в **консоли хостинга** командой `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`. Передайте боту только значение `SHA256:…`, затем пароль SSH отдельным сообщением. Установщик удаляет сообщение с паролем из чата перед подключением. Пароль используется из памяти для одной операции. Для установки или проверки удобно использовать временный пароль.
5. Дождитесь сообщения о запуске и откройте `/panel`. Для HTTPS на VPS должны быть свободны и доступны извне TCP 80 и 443. Caddy получает сертификат на публичный IP. Если контейнеры уже запущены, а сертификат ещё выпускается, повторите `/panel` позже. [Сертификаты для IP](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability)
6. В настройках панели укажите Base URL и ID модели. Если поставщик ИИ требует ключ, введите его там же.

Один Telegram-бот принимает сообщения. Установленная на VPS копия Aster отвечает через тот же токен, а задания доставляются по HTTPS с отдельным ключом каждого VPS. Копии токена устанавливаются только на VPS, которые вы добавили через бота. Подключайте свои доверенные серверы. Вход через кнопку **Открыть Aster** связан с привязанным Telegram-аккаунтом. Пароль для обычного браузера можно посмотреть на VPS в `/opt/acter-aster/current/.env`.

## Команды

| Команда | Действие |
|---|---|
| `/install` | Установить или обновить Aster |
| `/load` | Повторно ввести данные SSH и увидеть CPU, RAM, диск и среднюю нагрузку |
| `/servers` | Показать установленные VPS |
| `/use 1` | Выбрать VPS для панели и задач |
| `/panel` | Открыть панель выбранного VPS |
| `/ask текст` | Поставить задачу Aster. Можно отправить фото или документ с подписью `/ask` |
| `/jobs`, `/result 1`, `/stop 1` | Список задач, результат с файлами или остановка задачи |
| `/cancel` | Закрыть форму ввода данных |

После обновления Aster использует прежние тома Compose с рабочей папкой и SQLite. Повторная установка копирует настройки панели из последней успешной версии. Чтобы посмотреть состояние контейнеров на VPS, выполните команды из-под пользователя с доступом к Docker.

```bash
cd /opt/acter-aster/current
docker compose -p acter-aster --profile https ps
docker compose -p acter-aster --profile https logs --tail 100 app browser caddy
```

В панели доступны планы, максимум три субагента и задачи до 600 минут. Файлы, вложения и результаты доступны через Mini App и бот. См. [описание возможностей Aster](node/README.md).
